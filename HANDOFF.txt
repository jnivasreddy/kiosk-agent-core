KIOSK AWS HANDOFF: FASTAPI BACKEND + STREAMLIT CLIENT
==================================================

Nothing has been deployed. This prepares code for the AWS training team.

CURRENT ARCHITECTURE

Browser -> Streamlit app.py -> HTTP -> FastAPI api.py
  -> agent.respond() -> kiosk tools -> SQLite

Frontend: display conversation, menu, tool calls and saved draft.
Backend: validate input, retain model history, execute tools and read/write orders.
The UI imports neither agent.py nor database.py. OpenRouter calls happen only
in the backend. No payment, real login or checkout is implemented.

LOCAL RUN (two terminals, ai-dev activated, from this folder)

Install: python -m pip install -r requirements.txt
Backend: python -m uvicorn api:app --host 127.0.0.1 --port 8080
Frontend: python -m streamlit run app.py

UI: http://localhost:8501
Interactive API docs: http://localhost:8080/docs
Optional UI backend override in .env: KIOSK_API_URL=http://127.0.0.1:8080
No servers start merely by importing the modules.

LOCAL REQUEST EXAMPLE

curl http://127.0.0.1:8080/chat \
  -H 'Content-Type: application/json' \
  -H 'X-Amzn-Bedrock-AgentCore-Runtime-Session-Id: classroom-session-00000000-0000-0000-0000-000000000001' \
  -d '{"prompt":"Read the menu and save one cold coffee."}'

Use the same session header for GET /order and POST /reset.
GET /menu and GET /ping need no session. POST /invocations is a chat alias.
Missing/invalid request fields return 422. Provider/agent failures return 502
with a safe message; inspect backend logs and refresh the saved order before
retrying because a tool write can succeed before a later model call fails.

FILES

agent.py       Existing LangChain model/tool loop.

The SDK's previous BedrockAgentCoreApp server was replaced. Do not start it
alongside FastAPI. No Bedrock AgentCore SDK is required to serve this backend.
AWS boto3 is only needed by a future cloud client/deployment process.

AGENTCORE DEPLOYMENT LATER

For source packaging, include runtime.py, api.py, agent.py, tools.py, database.py
at the ZIP root with installed Linux ARM64/Python 3.12 dependencies from
requirements-agentcore.txt. Keep requirements-api.txt and requirements-core.txt
available during the build because dependency files reference them.

Do not package .env, SQLite files, tests, Streamlit, virtual environments,
__pycache__ or local credentials. Use an explicit source allowlist, not ZIP .

runtime.py serves api.app on 0.0.0.0:8080 and defaults the database to
/tmp/kiosk-agentcore.sqlite3. /ping and /invocations implement the default
AgentCore HTTP paths. Verify session header forwarding in the target account.
Supply the OpenRouter key through approved runtime configuration, not Git.

Important: standard AgentCore invocation is a managed /invocations operation.
It does not expose our auxiliary /menu, /order, /reset paths as arbitrary public
REST APIs. The AWS team must either add explicit invocation actions for those
operations, or expose a suitable authenticated backend API surface. Do not
point KIOSK_API_URL at a Runtime ARN or assume localhost-style routes work there.
Keep cloud client integration as a separate, tested deployment step.

For ordinary FastAPI hosting (e.g. an authenticated container service), these
REST routes can be exposed directly with the appropriate networking/auth setup.
This handoff does not select or create that infrastructure.

STATE / IDENTITY LIMITS

The random browser session ID scopes the draft and history; it is not verified
customer authentication. Anyone who has a session ID can address that session
on an unprotected server. Bind authenticated users to sessions before public use.

Use ONE backend worker. Model history and session locks live in that process;
multiple workers would have inconsistent histories. SQLite persists only on
the chosen local filesystem. AgentCore sessions are isolated, and /tmp/history
are disposable, not durable shared customer data. Use external state before
scaling or promising durable cross-session orders.

VERIFICATION

python -m unittest discover -s tests -v

Checks use FastAPI TestClient and Streamlit AppTest without binding real ports.
They verify order isolation, history, cart preservation, reset, validation,
safe provider errors, the /invocations alias and UI error handling. No AWS
resources or paid model calls are required.

The current server emits ordinary logs. Detailed CloudWatch model/tool spans
still need explicit ADOT/framework instrumentation and Transaction Search setup.

DEPLOYMENT GUIDE

See AGENTCORE_SETUP.txt. Keep the AWS account/region, role, secrets, artifact
storage, observability, invocation client, verification and cleanup decisions
with the AWS team. No deployment is performed by the application or tests.

REDIS UPDATE: history.py now loads/saves conversations in Redis when REDIS_URL
is set. Include history.py in the deployment ZIP and configure REDIS_URL in AWS.
Without REDIS_URL, local process memory is used. Customer login and session-owner
mapping are not implemented yet. See FLOW_CORRECTED.md for current and planned diagrams.
